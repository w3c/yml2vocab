This document describes the Recognized Entities Vocabulary, i.e., the RDFS [[rdf-schema]] defined by the [[[?vc-recognized-entities]]] [[?vc-recognized-entities]] specification..

Alternate versions of the vocabulary definition exist in Turtle and JSON-LD.

Published:
2026-10-19
Version Info:
1.0
See Also: https://www.w3.org/TR/vc-recognized-entities/

This vocabulary has been defined by the W3C Verifiable Credentials Working Group and provides the official RDFS vocabulary for Recognized Entities 1.0 specification. Comments regarding this document are welcome. Please file issues directly on GitHub, or send them to public-vc-comments@w3.org (subscribe, archives).

    Class definitions

    The following are class definitions in the re namespace.

    RecognizedEntity

    Recognized Entity

    See the formal definition of the term.

    An entity that is recognized in a Recognized Entity Credential to perform a specific action.
    Domain of:
    recognizedTo
    In the domain of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognized-entities/v1

    RecognizedAction

    Recognized Action

    See the formal definition of the term.

    An action that a Recognized Entity is expected to perform.
    Range of:
    recognizedTo
    Domain of:
    action, recognizedBy, outputValidation
    Relevant @context:
    https://www.w3.org/ns/credentials/recognized-entities/v1

    RecognizedEntityCredential

    Recognized Entity Credential

    See the formal definition of the term.

    A conforming verifiable credential, as defined in [[[?vc-data-model-2.0]]], that encapsulates Recognized Entities.
    Subclass of:
    cred:VerifiableCredential
    Includes the range of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognized-entities/v1

    RecognizedIssuer

    Recognized Issuer

    See the formal definition of the term.

    In the domain of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognized-entities/v1

    ExternalEntityList

    External Entity List

    See the formal definition of the term.

    A list of external entities that are usually in a different format such as an x509 Certificate Authority List or an ETSI Trust Services List.
    Includes the range of:
    recognizedIn
    Relevant @context:
    https://www.w3.org/ns/credentials/recognized-entities/v1
